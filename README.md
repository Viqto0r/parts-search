# Поиск запчастей и аналогов

Одностраничное приложение для подбора автозапчастей по API Favorit Parts. Сначала вводится артикул
и выбирается производитель, затем показывается таблица с самой деталью и её аналогами: название,
производитель, цена и остаток.

## Запуск

```
cp .env.example .env
npm install
npm run dev
```

В `.env.example` лежит демо-ключ из документации API, он рабочий. Свой ключ задаётся в
`VITE_FAVORIT_API_KEY`.

## Тесты

```
npm run test:run
npm run coverage
```

## Стек

React 19, Vite, Redux Toolkit, Bootstrap 5 (только CSS), Vitest и React Testing Library.

## Заметки

- Цена в таблице — минимальная среди складов (`warehouses[].price`). Поле `price` на уровне товара
  документация использовать не советует. Если цены на складах разные, перед ценой стоит «от».
- Одна строка таблицы — один товар, а не товар на каждом складе: у позиции бывает до 18 складов, и
  таблица разрослась бы в разы. Остаток берётся из `count` (сумма по складам).
- API иногда обрывает соединение, поэтому у запроса таймаут 15 секунд, а при ошибке показывается
  сообщение и кнопка «Повторить». Автоматических повторов нет. Поиск по мере ввода идёт с
  задержкой 600 мс, быстрый ввод отменяет предыдущий запрос.
- На втором шаге передаётся номер выбранной позиции, а не введённый: у производителя он может
  отличаться (например, `H01089-00` у GLASER).
